# AI Study Optimizer

## Deskripsi Proyek

AI Study Optimizer merupakan aplikasi web berbasis Artificial Intelligence yang digunakan untuk mensimulasikan optimasi rencana belajar mahasiswa menggunakan tiga algoritma optimasi, yaitu:

* Hill Climbing
* Simulated Annealing
* Genetic Algorithm

Aplikasi memungkinkan pengguna menentukan total jam belajar per minggu, kemudian sistem akan mengalokasikan waktu belajar ke beberapa mata kuliah berdasarkan nilai fitness terbaik yang dihasilkan oleh algoritma yang dipilih.

---

## Fitur Utama

* Simulasi Hill Climbing
* Simulasi Simulated Annealing
* Simulasi Genetic Algorithm
* Perbandingan nilai fitness
* Visualisasi hasil menggunakan grafik
* Antarmuka web interaktif

## Cara Menjalankan Program

### Clone Repository

```bash
git clone https://github.com/USERNAME/ai-study-optimizer.git
```

### Masuk ke Folder Project

```bash
cd ai-study-optimizer
```

### Install Dependency

```bash
pip install -r requirements.txt
```

### Jalankan Program

```bash
python app.py
```

### Buka Browser

```text
http://127.0.0.1:5000
```
